# 🚗 Carros Antigos com CSS

Projeto de desenvolvimento web que apresenta **carros antigos em páginas HTML**, com estilização em **CSS**. Desenvolvido como atividade de Programação Web por **Melissa Barbosa Crepaldi** e **Helena Oliveira Seixas**.

## 🌐 Acesse o projeto

[Visualizar o site publicado na Vercel](https://licao-pw-css-2.vercel.app/)

## 🎯 Objetivo

Praticar a criação e organização de páginas web usando HTML para estruturar o conteúdo e CSS para personalizar sua apresentação visual, com o tema de carros antigos.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura das páginas.
- **CSS3:** aparência, estilos e elementos de navegação.
- **Vercel:** publicação do site.

## 📁 Estrutura do repositório

```text
licao-pw-CSS2/
├── CSS/                # Arquivos de estilo
├── HTML/               # Páginas HTML
├── imagens/            # Imagens utilizadas no site
├── videos/             # Recursos de vídeo
├── index.html          # Página inicial
├── styleBotoes.css     # Estilos dos botões
├── styleindex.css      # Estilos da página inicial
└── README.md           # Documentação
```

## ▶️ Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/MelissaCrepaldi/licao-pw-CSS2.git
   ```
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.

Também é possível acessar diretamente a versão publicada pelo link acima.
